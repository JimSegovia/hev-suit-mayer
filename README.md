# HEV Suit Mayer

Traje HEV de cartón para mi hermano. Visor 3D con maniquí a sus medidas + diseños y plantillas.

| Carpeta | Contenido |
|---|---|
| raíz (`index.html`, `app.js`, `child.js`, `styles.css`) | Visor 3D con el maniquí. Se abre con `abrir-local.ps1` |
| `vendor/`, `dist/`, `images/`, `models/` | Librerías, copia publicada, silueta y modelos 3D del visor |
| `blender/` | Scripts y `.blend` de las pruebas en Blender |
| `disenos/` | Imágenes de diseño por pieza (`antebrazo`, `brazo-superior`, `guante`, `hombros`, `cuerpo-completo`) |
| `plantillas/` | Plantillas SVG para imprimir en A4 y `carton_pattern.py` que las genera |
| `herramientas/` | Scripts y webs auxiliares (`fetch_model.py`; `separador-hojas` tiene su propio repo y no se sube) |
| `web de imagenes/` | Web local para dividir/escalar imágenes en hojas A4 (`node server.js`) |
| `imagenes de referencia/` | Fotos y plantillas de referencia (`plantillas-pepakura-eva`, `pepakura-pdo`, `hojas-a4-numeradas`, `ia-generadas`) |
