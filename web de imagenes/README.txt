Separador de hojas A4

Para abrir la web local:
1. Abre una terminal en esta carpeta.
2. Ejecuta: node server.js
3. Visita: http://127.0.0.1:4173

Modo escala e impresión: http://127.0.0.1:4173/escala.html
Permite cargar varias imágenes, compararlas con un rectángulo de medidas
reales y calcular/imprimir las hojas A4 necesarias para cada una.

También puedes abrir index.html directamente en el navegador.
La imagen se procesa en tu navegador y no se sube a internet.
